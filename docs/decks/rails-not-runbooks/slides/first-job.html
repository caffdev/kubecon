Fenced in is where an agent starts. How does it earn more? The same way a release earns a wave. Across the top, five rungs, from Transfix's talk. Shadow mode: the agent decides, but the action is withheld. Then its work is graded against what actually happened. Then an eligibility rule, code that gives the same answer every time, says it's ready. Then a permission pull request, reviewed by people. And the revoke is designed before the grant. Their line: models produce evidence; code decides authority. Rung one is a real job with no write path: explaining alerts. Click. Payments is crash-looping on aws-1 prod. The agent reads and posts: real, not noise; Argo CD synced payments twelve minutes ago; suggestion, roll back with one revert PR. It doesn't act. Nothing to sandbox, nothing to gate. Click. The responder accepts, modifies or rejects, and every choice is logged. That log is the track record the agent needs before it's allowed to open that PR itself. Click. Receipts.
