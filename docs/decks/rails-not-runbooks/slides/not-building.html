Before the ask, what we won't build. It matters as much as what we will, because a plan has to stay small enough to finish. No GPUs, no model serving. About a third of the AI talks at the show were about running models. We never will. We call Claude, through the same gateway every agent uses. No second container orchestrator. ECS wouldn't replace anything; it would be a third platform to run. EKS everywhere in AWS, Auto Mode by default. No agent framework of our own. Claude runs headless in the Job you saw; we build the box it runs in, not the brain. No promotion product. The waves are an ApplicationSet and the gate is a Job, in the Argo CD we already run. No new observability backend. OTel in front of Prometheus, Grafana and Splunk, which all stay. And no developer portal before the road exists. Every company at the show that made deploying boring built the path first; the portal came after, as a window onto it. That leaves five pull requests.
