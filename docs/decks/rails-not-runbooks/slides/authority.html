“Models produce evidence. Code decides authority.”Transfix · Darian DeFalco, Progressive Delivery for Trust: How Agents Earn the Right to Merge · KubeCon NA 2026. The proposer can't approve its own PR; the forge enforces merge rules.

Every control so far says what an agent can't do. This one says how it gets to do more, and it's the single most copyable idea we brought home, from Transfix. Take the rails we already built for releases and swap the payload. Instead of a version rolling out, the thing being rolled out is authority. The top row is the first half of this talk: a new version goes to the canary wave, the gate Job checks it, exit zero passes, the next wave gets it, and a failed gate stops the wave and the revert is a commit. The bottom row is the same rails pointed at an agent. The canary is shadow mode: the agent decides, and the action is withheld; a person sees what it would have done. The gate is grading its work against what actually happened. Passing is an eligibility rule that gives the same answer every time, not a feeling. The next wave is a reviewed permission change, a pull request like any other. And the stop is revoking the grant, which we design before we grant anything. "Models produce evidence. Code decides authority." It needs nothing we don't already run: the pipeline, RBAC for what each role can touch in a cluster, repository rules for who can merge. Rung one, shadow mode, is where every agent starts. So here's what shadow mode looks like on a real job: the next alert.
