Now the third way agents arrive: in attackers' hands. They find holes in what we run faster than we've ever had to patch them. The answer isn't more people. It's closing the circle. From the top. A new CVE lands, found by their AI or anyone's. The lake finds it: one query, which clusters run the affected image. Our agent drafts the fix as a pull request, a one-line diff to a new image digest. CI runs the same rules as anyone's change, and the team approves; the agent that proposes can't approve its own PR. Transfix put that in six words: models produce evidence, code decides authority. Then the waves from the first half ship it, each step gated on status. In the middle: days, from a CVE to every cluster. Same team, same pipeline; the agents make it go round faster. Click. And NVIDIA already did the last step at speed. Their slide: an agent drove a patch across sixteen clusters, about fifty-six hundred nodes, in thirty minutes, for two kernel CVEs days apart. Look how little it was trusted with. It applies the change and polls one status field. Complete: next cluster. Erroring or blocked: stop and call a person. Their line: the next CVE is a YAML change. Five first pull requests get us there.
