Every one of those clusters also runs the platform: Argo CD to deploy, Prometheus to measure, the Splunk OTel collector to ship telemetry, and Karpenter to scale nodes on the cloud clusters. Each of those has its own release train. Prometheus ships a minor about every six weeks. Argo CD about every three months. The OTel collector every few weeks. Karpenter every month or two. Those are rough, and they don't line up with each other or with Kubernetes. So here's the fleet, twenty-nine clusters across the top, the four tools down the side. Four tools for now, to keep the picture readable; the real list comes back later. Each square is how far that cluster's copy is behind the latest release. Dark is current. Pale is one behind. Hollow is two or more. Dashed means nobody's quite sure without logging in. The blanks are Karpenter on our own hardware, where it doesn't run. This is what hand rollouts leave behind. Not because anyone's careless: because each release is another twenty-odd rollouts by hand, and the next release lands before the last one's finished. The grid is illustrative, but anyone who's run a fleet will recognise it. Now add the clusters and the tools together, and put them against one person's year.
