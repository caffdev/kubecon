Four things, and the first two are the ones I'm asking for today. One: no new hand-built clusters. New clusters in AWS are EKS Auto Mode; new clusters on-prem come from Cluster API. kubeadm is still there underneath, but the runbook retires. Two: one tool through the pipeline this quarter, and I'd start with the Splunk OTel collector. It's on every cluster, we can see from Splunk whether its data is arriving, so its gate is easy to write, and it's the layer we just talked about. Waves, gates, automatic rollback. Once it works, Argo CD, Prometheus and Karpenter follow the same path. Then, three: change windows as a policy. One window, stored in the cluster, that Argo CD and Kyverno both read. And four: the OTel collector on every cluster, AI workloads included, feeding one read-only lake that the agents read instead of holding production credentials.
