EKS arrived, so now we upgrade two kinds of cluster two different ways.

Then AWS. We stood up EKS: a dev cluster, and two prod clusters in two regions, east and west, so our public apps could run live-live. EKS is a different animal. AWS runs the control plane, but the node groups, the add-ons and the order you do them in are on us, and none of it looks like the kubeadm runbook. So now there are two runbooks, for two kinds of cluster. Six clusters. Still one person. And once EKS made clusters easy to get, everyone wanted one.
