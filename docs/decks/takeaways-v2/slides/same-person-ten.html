Same person, fourteen times the clusters: now he approves waves, and the pipeline runs them.

Here's the picture we started with: one person, two clusters, and twenty-six dashed outlines still to come. They came. Twenty-eight clusters, the same row. And the same one person. What changed is what he does. He doesn't walk each cluster through a runbook any more. He approves a wave, and the pipeline runs it: test, canary, wave one, wave two, prod, with a gate between each, inside the window, rolling itself back if a gate fails. Every cluster is lit because every one is on the version the pipeline delivered, not the version someone got round to. Fourteen times the clusters with the same person only works because he isn't doing the work by hand. For scale, Meta runs about a hundred clusters with about fifteen engineers.
