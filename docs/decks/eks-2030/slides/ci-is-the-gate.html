We're keeping Argo CD basic: no promotion tools, no progressive sync. So where does safety come from? Two gates, both boring. The first gate is CI, before anything merges. It renders the chart, checks the schema, runs policy, and checks the rules the API server would reject anyway. Click. Ford runs hundreds of clusters this way, with pull requests coming from people, from AI and from bots. Deterministic CI means reviewers read the content, not the syntax. The second gate is after the sync: an Argo CD PostSync hook, which is just a Job with one annotation. It runs a smoke test against the thing that just deployed. If it passes, the next wave goes. If it fails, the wave stops and a person gets paged; that's the red branch. Click. LinkedIn built exactly this and went from a week of hoping to an hour of proof, with more than ten incidents caught before production. EarnIn wires infrastructure tests into GitOps the same way, and caught cert-manager breaking silently and backups that never actually ran. Now the pods are running.
