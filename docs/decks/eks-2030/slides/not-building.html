What we will not build

GPUs, model serving, DRAInstead: we call Claude
A second orchestrator or cloudInstead: EKS, on AWS
Kargo, Promoter, progressive syncInstead: plain Argo CD, CI and hooks
Our own agent frameworkInstead: the Claude Agent SDK; we build the box, not the brain
A new observability backendInstead: Prometheus, Grafana and Splunk stay
An agent platform productInstead: compose the parts we already run
What we won't build matters as much as what we will. A startup's plan has to stay small enough to actually finish. No GPUs, no model serving. We call Claude. No second orchestrator and no second cloud. EKS, on AWS. No Kargo, no GitOps Promoter, no progressive sync. Plain Argo CD, with CI and a PostSync hook as the gates. No agent framework of our own. The Claude Agent SDK is the brain; we build the box it runs in. No new observability backend. Prometheus, Grafana and Splunk stay; we put one pipeline in front of them. And no agent platform product. IBM's point was that you already run the parts. That leaves three things to decide today.
