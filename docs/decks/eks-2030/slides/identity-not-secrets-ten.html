Sheet three: identity, not secrets. Top left is how most platforms start: a password in an environment variable. Long-lived, copied around, never rotated. We void that from the first cluster. Instead, every pod gets one identity. Istio gives each pod a SPIFFE ID and a short-lived certificate for mutual TLS. Vault trusts the same identity and hands out database credentials that expire. And AWS access goes through EKS Pod Identity, so there are no static keys anywhere. Click. Coinbase is revision A from the cover sheet. They did this as a retrofit, across four thousand services in seventy-nine clusters. CPU dropped seventy percent, each hop got four to ten milliseconds faster, and they reached a hundred percent adoption. We get that by turning it on before the first app arrives. Click. One decision we owe ourselves before the first production cluster: sidecar or ambient mode for Istio. Coinbase is moving to ambient. It's in a cloud because it's open. Istio gives us identity. At scale it will also give us two million metric series, if we let it.
