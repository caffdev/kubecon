Path 2 is the one everyone is looking at, and the main thing to say about it is what it isn't. It isn't an agent platform we build from scratch. Claude comes off the laptop and runs headless in a throwaway pod, started by Jenkins, which we already run. The pod gets a short-lived identity and no static key, in one namespace. Its only ways out are a gateway, which every model call and tool call goes through, and telemetry, so every call is a span with a team and a cost on it. After the run, the pod is gone. Four phases. Phase 0 is laptops, now: telemetry on, and one shared marketplace for skills and MCP configs. The two in orange are the dates we're asking for. Phase 1, by Q2 2027: read-only agents, starting with alert triage. That one is safe, because triage never writes anything. Phase 2, by the end of 2027: agents open pull requests, and review is unchanged. That one is the bet, and it's dated after Path 1's stage B on purpose, because of the rope. Phase 3 is 2028, and it's a decision we make with real data. The detail is its own deck, Path 2: Claude off the laptop, into the pod. And Path 3 is the ground the other two stand on.
