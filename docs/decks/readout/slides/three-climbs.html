Base camp: Argo on manual sync, clusters named by hand, Claude on laptops.

From base camp, three climbs. Each has its own stages, numbered the way its own plan numbers them. Path 1, up the middle: delivery. Stage A turns Argo into a control loop. B is policy, one set in CI and at admission. C makes promotion a pull request. D rolls changes across the fleet in waves. E is the summit: deploying becomes a service. Path 2, on the right: agents. Phase 0 is laptops: telemetry and one shared marketplace. Phase 1 is read-only agents in CI, starting with alert triage. Phase 2, agents open pull requests. Phase 3, teams add their own agent jobs without a ticket to us. Path 3, on the left: the fleet. Stage 1 makes cluster labels an API. Then fleet delivery, then cluster lifecycle, then Crossplane for the infrastructure app teams own. They look independent. Two ropes say they aren't.
