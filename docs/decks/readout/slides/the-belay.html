So where are we standing? Base camp, along the bottom. Let's say it plainly, because everyone here knows it. Our clusters have names people know by heart and get upgraded one at a time. Argo CD is in every cluster, on manual sync: a dashboard somebody clicks. And Claude runs on laptops, with skills passed round in Slack. None of that is a failure. It's an honest starting point. From there, three climbs. Path 1 up the middle: delivery, stages A to E. Path 2 on the right: agents, phases 0 to 3. Path 3 on the left: the fleet, stages 1 to 4. Mostly they're independent, which is why we can staff them in parallel. But two ropes tie them together, and one of them decides what we protect. Click. The rope runs from Path 1, stages B and C, across to Path 2, phase 2. Stage B is one policy set, run in CI and at admission. Stage C makes promotion a pull request. Phase 2 is the first time an agent opens a PR. An agent's PR is only safe because the same policy and the same promotion path check it that check a human's. So no agent opens a PR until policy runs in CI. That's the belay. Pause on that. The least visible work on Path 1, a policy layer nobody demos, gates the most visible work on Path 2. If one piece of work gets protected headcount, it's stage B. Click. The second rope is thinner. Path 3's first stage is a cluster-label vocabulary, and Path 1's stage D rolls changes across the fleet by selecting on those labels. That one's nearly free to start, which is why Path 3 starts now. Each climb in one slide, starting with the one the others are belayed to.
