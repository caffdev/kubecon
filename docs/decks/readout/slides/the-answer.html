This is the answer, so we're putting it first. One path to production for every change, whoever or whatever wrote it. We build it as three climbs, and all three start this quarter. The picture is the show's own artwork: the Wasatch range you could see from the convention centre. Three summits from one base camp. The centre one is the tallest because it's the one the others depend on: Path 1, making deployment a service. On the right, the sharpest and newest: Path 2, getting Claude off laptops and into pods we control. On the left, the broadest: Path 3, the EKS fleet and Crossplane, the ground the other two stand on. Peak height is ambition, not priority. Path 3 is widest because everything else stands on its cluster-label vocabulary. Why one path? Because two things got loud this week, and they turn out to be the same problem.
