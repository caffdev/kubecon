Camp one is close, so let's define what reaching it means, because if the output is a summary nobody acts on, we've built a chatbot. This is an illustrative triage, not a real one. An alert fires. The agent posts four things, and these are the acceptance criteria. A relevance call: real, noise, or a duplicate of an open incident, with its reasoning. A severity, stated in terms a responder can disagree with. Links out: the runbook, the dashboard, the deploy that correlates, the last three times this fired. And a suggested action. Then the responder accepts it, modifies it, or rejects it, and we log which. That log is the product. It's the track record that stage 2, agents opening pull requests, is gated on. If we don't instrument it from day one, we arrive at the next gate with no evidence. We don't start from scratch.
