Here's the whole runtime on one slide, and the point is how little of it is new. Left to right. Something happens: a pull request opens, an alert fires, someone types a command in Slack, or the nightly cron runs. Jenkins picks it up, as it already does for everything else, with credential binding, audit logs, retries and a UI people know. It calls one shared library step we write, claudeAgent. That starts a throwaway pod in a namespace of its own, running an agent image we build: Claude Code headless, with managed settings baked in, plugins pulled from our marketplace, and telemetry on. The dashed line is the namespace's network policy. The pod can only talk to two things: the gateway, and the telemetry collector. Every model call goes through the gateway to the Anthropic API or Bedrock. Every tool call goes through it to GitHub, Jira, Grafana and a read-only view of Kubernetes. Quota, auth and audit live there, once. Teal is what we build. Four things: the agent image, the library step, the marketplace, and the gateway. Grey is configuration of things we already run. The marketplace is the piece laptops get first, so let's look at that.
