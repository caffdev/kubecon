Here's the turn. We could build all four of those walls into a new agent platform. We think that's the mistake. Don't build an agent platform. Run Claude Code headless, in throwaway pods, through the CI system we already trust. Jenkins already gives us triggers, credential binding, audit logs, RBAC, retries, queueing, and a UI people know. Kubernetes already gives us isolation, quotas and network policy. That's most of a platform, and we already run it. What's missing is four things. Click: a hardened agent image. Click: one shared, versioned marketplace of skills, MCP configs and settings. Click: a gateway that every model call and tool call passes through. Click: telemetry that tells us what each run did and what it cost. Build those four things and let everything else be Jenkins. Those four gaps are the whole build.
