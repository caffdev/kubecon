Before anything else: scope. We run Claude. We are not building or hosting a model. Inside our boundary: engineers using Claude Code every day, with a human approving every change. Agents we write that call Claude through the API or Bedrock. The Agent SDK, which is the Claude Code harness as a library, running in our own pods. And the MCP servers those agents reach. Deliberately outside: GPU scheduling, device allocation and quota; model-serving stacks like llm-d, vLLM and KServe; training and fine-tuning. Roughly a third of the week was about those. It was excellent engineering, and none of it is our problem. Buying inference means our hard problems are the ones at our boundary: what an agent may touch, with whose identity, what it costs per task, and how we know what it did. And if we do nothing, here's what running Claude turns into.
