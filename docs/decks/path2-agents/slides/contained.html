Here's the security question in one picture, roughly to scale. The big circle is a laptop's reach today: everything one engineer's credentials touch. Every repo, the cloud console, a production kubeconfig, Slack and email. When Claude runs on that laptop, that's its blast radius. The small glowing circle is the agent pod. One namespace. Network policy means it can only leave through named exits: the AI gateway for model calls, the MCP gateway for tools, and the telemetry collector. No general internet. That one control turns prompt injection from "exfiltrate the repo" into "post a weird PR comment", and we assume injection, because every alert body and PR description is text someone else wrote. Four keynotes this week, among them Agent Substrate, Sandbox Your Agents and The Identity Crisis, asked the same four questions of any agent. Here are our answers. Identity: Bedrock through IRSA, or a token the gateway issues; no static key anywhere. And when it's time to write, a GitHub App token for one repository, pushing only to claude-slash branches. Egress: named exits only. Sandbox: a hardened pod now, non-root with a read-only filesystem, and microVMs once agents start fixing things. Session: the pod is thrown away when the job ends. And the cluster it only ever reads, through MCP. No write credentials at all. That's how far it can reach. The next question is how it earns the right to do more.
