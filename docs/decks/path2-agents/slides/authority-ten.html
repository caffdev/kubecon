“Models produce evidence. Code decides authority.”Darian DeFalco, Transfix

This is the single most copyable idea we brought home, from Transfix's talk, Progressive Delivery for Trust: How Agents Earn the Right to Merge. Take progressive delivery, which we already run for releases, and swap the payload. Instead of traffic, the thing being rolled out is authority. The top row is a release in Argo Rollouts. A canary step sends a slice of traffic. Analysis queries Prometheus. Success is an error rate under a threshold. Promotion means more traffic. Abort means roll back. Click. The bottom row is the same five steps, pointed at an agent. The canary is shadow mode: the agent decides, and the action is withheld. Analysis grades its work against outcomes. Success is an eligibility policy that gives the same answer every time. Promotion is a reviewed permission change: a pull request. And abort is revoking the grant, which we design before we grant anything. Models produce evidence. Code decides authority. The agent never promotes itself, and the proposer can't approve its own PR. It needs nothing we don't already run: Rollouts, RBAC, and repository rules. And none of it works unless we can see what the agent did.
