The marketplace is the piece laptops get first, before any agent runs anywhere. Today, on the left: the skills and MCP configs people find useful get passed person to person, in Slack. Every copy drifts a little. There's someone's version two, someone's fork, and nobody knows which one is current or safe. On the right: one versioned repo, owned by the platform team, with contributions by pull request from anyone. Every laptop and every agent pod reads from the same place, so the agent in a pod behaves like the engineer at the terminal, because it's using the same skills and settings. And MCP servers run centrally rather than being shipped to every laptop. Phase 0 is mostly this, which is why it starts on laptops. And when it runs in a pod, here's how far it can reach.
