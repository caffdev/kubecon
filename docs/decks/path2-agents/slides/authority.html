"Models produce evidence. Code decides authority."Darian DeFalco, Transfix, "Progressive Delivery for Trust: How Agents Earn the Right to Merge". Four roles: the proposer can't approve its own PR; the forge enforces merge rules.

This is the single most copyable idea we brought home, from Transfix. Take progressive delivery, which we already understand for releases, and swap the payload. Instead of traffic, the thing being rolled out is authority. The top row is a release in Argo Rollouts: a canary step sends a percentage of traffic, analysis queries Prometheus, success is an error-rate threshold, promotion means more traffic, and abort means roll back. The bottom row is the same primitives pointed at an agent. The canary step is shadow mode: the agent decides, and the action is withheld. Analysis grades its work against outcomes. Success is an eligibility policy that gives the same answer every time. Promotion is a reviewed permission change, a pull request. And abort is revoking the grant. "Models produce evidence. Code decides authority." And it needs nothing we don't already run: Rollouts primitives, RBAC for what each role touches in the cluster, and repository rulesets for what can happen in the repo. Design the revoke path before granting anything. And none of that works unless we can see what it did.
