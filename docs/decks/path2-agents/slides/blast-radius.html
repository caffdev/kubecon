Here's the security question, answered in one picture, drawn roughly to scale. The big circle is a laptop's reach today: everything one engineer's credentials touch. Every repo, the cloud console, a production kubeconfig, Slack and email. When Claude runs on that laptop, that's its blast radius. The small dashed circle is the agent pod. One namespace. Network policy means it can only leave through the two gateways, one for model calls and one for tools, plus the telemetry collector. On the right, how. Identity: Bedrock through IRSA, or a token the gateway issues; no static key anywhere. Git: a GitHub App token scoped to one repository, allowed to push only to claude-slash branches, with main protected. The cluster: read-only, through MCP servers, with no write credentials at all. A hardened pod now, microVM sandboxing when agents start acting. And every trigger payload, an alert body, an issue description, is treated as untrusted input, because prompt injection is a when, not an if. Reach is one half. The other is how an agent earns more of it.
