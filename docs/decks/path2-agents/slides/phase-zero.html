All of this starts on laptops, this month, and nothing in phase 0 needs a write path anywhere. Four phases along the top. Phase 0 is laptops, now to January. Phase 1 is read-only agents in CI, February to Q2, which is our stage-1 alert triage. Phase 2 is agents opening pull requests in the second half of 2027. Phase 3, teams adding their own agent jobs, is a 2028 decision we make with real data. Phase 0 is five things. Turn on telemetry on every desktop through managed settings; two to four weeks of that data is the inventory of what we use AI for. Move everyone to org-provisioned auth, so personal API keys stop working on company repos. Ship a managed settings file with the org-wide deny list. Stand up the marketplace repo and move in the five to ten skills people already pass around. And commit a CLAUDE.md in each service repo, because the agents in pods will read the same file. The exit gate: eighty percent of active users reporting telemetry, a marketplace with an owner and a review process, and the top five use cases named from data rather than anecdote.
