All of this starts on laptops, this month, and nothing in phase 0 needs a write path anywhere. On the left is what we change on every laptop between now and January. A managed settings file, pushed by device management, that turns telemetry on and carries the org-wide deny list. Org-provisioned auth, Enterprise seats or Bedrock through single sign-on, so personal API keys stop working on company repos. The marketplace repo, with the five to ten skills people already pass around in Slack moved into it. And a CLAUDE.md in every service repo. On the right is the agent pod from February. Every row carries across. The same managed settings, baked into the image. The same identity rule, as workload identity with no keys. The same plugins, pinned to a reviewed tag so an automated job never picks up an unreviewed skill. The same CLAUDE.md. The only thing that doesn't cross is someone's personal config. If a job only works because of something in a person's home directory, that's a bug. The exit gate: eighty percent of active users reporting telemetry, a marketplace with an owner and a review process, and the top five use cases named from data rather than anecdote. So here's what we need decided.
