Session titles and abstracts, KubeCon NA 2026

The teams we heard from who run agents in production all did the opposite of that default, and they had operating numbers, not demos. Verkada: thirty-three cents per alert triaged, four thousand seven hundred a month, nine production clusters. Podium: thirty percent of their merged pull requests come from autonomous Kubernetes coding agents. Mastercard: an LLM driving thirty EKS clusters in production, through a narrow set of live tools rather than a search index. Salesforce: a thousand clusters under agentic AIOps. Different companies, same shape. The agent proposes. A pull request, a recommendation, a triage note. And progressive delivery and policy decide what actually happens. Nobody argued for an agent with production credentials and no gate. And four keynotes named what any agent needs before it runs.
