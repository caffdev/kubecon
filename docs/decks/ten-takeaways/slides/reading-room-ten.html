READ ONLY

Rule nine, and the first thing camp one needs: something to read. Reading room only. A reference library is the best-known place where you may read everything and take nothing out. That's the access rule for agents. They study a read-only copy of production: cluster state dumped to a database on a schedule, metrics queried from Prometheus, and where freshness matters, a small set of narrow, audited live tools. They get a desk in the reading room, never the keys to the stacks. NVIDIA and Upbound showed a queryable audit layer like this. Mastercard argued the other side well, against a stale index, for a narrow tool surface, and they run an LLM across thirty EKS clusters that way. Read-only extraction is how we say yes to agent analysis without saying yes to agent credentials in production. And it feeds camp one directly. And every page they read goes on the receipt.
